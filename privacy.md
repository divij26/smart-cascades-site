# Smart Dependent Dropdowns – Privacy Policy

_Last updated: 11 November 2026_

Smart Dependent Dropdowns ("the app", "we") is a monday.com app that lets one dropdown column depend on another. This policy explains what data the app handles and why.

## Who we are

Smart Dependent Dropdowns is built and run by Divij Sharma, London, United Kingdom, who is the data controller for the data below. Contact: [support@zedmere.com](mailto:support@zedmere.com).

## What we store

To make cascades work, our server stores only setup data:

| Data | Why |
|---|---|
| monday account ID | Keep each account's setup separate and apply its plan |
| Board ID and column IDs | Know which columns a cascade connects |
| Label IDs map (which child labels fit each parent label) | Filter the options in the picker |
| User ID of the person who last saved a cascade | Basic audit of changes |
| Your app plan (free or paid) and install/subscription events from monday | Apply plan limits |
| Created and updated times | Basic audit of changes |

We do **not** store item names, item values, label text, file contents, comments, or any personal details such as names or email addresses. The picker reads and writes board data directly through monday's API as the signed-in user, so monday's own permissions apply.

## Why we're allowed to use it

We use this data to provide the app you installed (performance of a contract) and to keep it secure and working (legitimate interests), as allowed by UK GDPR.

## Where data is kept

Data is stored on monday code, monday.com's hosting platform, in its EU region. 

## Third-party services

| Service | What for | Customer data? |
|---|---|---|
| monday code (monday.com) | Hosts the app's server and screens, and its database | Yes: the setup data above |
| GitHub Pages (GitHub) | Hosts this public website: support, privacy, terms and the how-to page | No |

We use no analytics, advertising, tracking, email or AI services.

## Logs and cookies

Our server logs only the monday account ID when an account uninstalls the app. Logs hold no board data and no personal details. They are kept by monday code under its own retention rules.

The app sets no cookies of its own and uses no tracking technology. This website sets none either.

## When we contact you

We contact you only to answer a support request you sent us, or to tell you about a security problem, a billing issue or a change to these documents. We send no marketing.

## Payments

Payments are handled by monday.com. We never see or store card details.

## Sharing

We don't sell or share your data. We only disclose it if the law requires us to.

## How long we keep it

We keep setup data while the app is installed. When an account uninstalls the app, monday notifies our server and we delete all of that account's data. You can also remove a single cascade at any time from the app's Setup screen.

## Your rights

You can ask us to see, correct or delete your data by emailing [support@zedmere.com](mailto:support@zedmere.com). We reply within 30 days. If you're unhappy with how we handle your data, you can complain to the UK Information Commissioner's Office ([ico.org.uk](https://ico.org.uk)).

## Security

Every request to our server must carry a session token signed by monday, which we check. Data travels over HTTPS. Only the app owner can reach the stored data.

## Changes

If we change this policy, we'll update the date above. Big changes will be noted on the [support page](./).
